# 障碍势能优化说明

## 版本 2.0 更新 (2025-12-26)

### 新增功能
1. **任务势能可视化** - 目标点附近显示负/低势能（吸引区域）
2. **总势能可视化** - H_total = H_barrier + H_task
3. **wandb Viz模块集成** - 三种势能图像自动上传
4. **增强安全学习** - 新增辅助损失函数降低cost

## 问题诊断

从SafetyCarMultiGoal1-v0环境的势能场可视化中发现：

1. **障碍物周围黑色区域过大** - 高障碍势能区域范围过广
2. **障碍物间完全被黑色覆盖** - 智能体无法穿过障碍物之间的间隙
3. **势能衰减过慢** - 远离障碍物后势能仍然很高

### 根本原因

障碍势能计算公式：
```
H_barrier = k / ((d - r_safe)^decay_rate + ε)
```

原始参数设置导致势能影响范围过大：
- `barrier_r_safe = 0.5` - 安全距离过大
- `barrier_epsilon = 0.005` - 太小导致势能过于陡峭
- `barrier_k_scale = 2.0` - 放大系数过大增强了整体势能强度
- `barrier_gradient_scale = 1.5` - 梯度放大系数过大
- `barrier_decay_rate = 2.0` - 衰减率较低，势能影响范围广

## 优化方案

### 参数调整对比 (v2.0 - 进一步优化)

| 参数 | 原值 | v1.0 | **v2.0** | 效果 |
|------|------|------|----------|------|
| `barrier_r_safe` | 0.5 | 0.25 | **0.15** | 进一步减小安全距离，使障碍势能边界更紧凑 |
| `barrier_epsilon` | 0.005 | 0.02 | **0.05** | 增大使势能更平滑 |
| `barrier_clip_max` | 100.0 | 50.0 | **30.0** | 降低最大势能限制 |
| `barrier_k_scale` | 2.0 | 0.8 | **0.5** | 大幅降低势能强度 |
| `barrier_gradient_scale` | 1.5 | 0.8 | **0.5** | 降低梯度影响 |
| `barrier_decay_rate` | 2.0 | 3.0 | **4.0** | 提高到距离⁴衰减，势能影响范围更小 |
| `min_barrier_k` | 0.5 | 0.2 | **0.1** | 降低最小基础刚度 |
| `cost_aware_weight` | 0.3 | 0.1 | **0.05** | 减少危险区域惩罚 |
| `danger_zone_threshold` | 0.8 | 0.9 | **0.95** | 只有非常接近障碍物才触发 |

### 新增辅助损失权重

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `aux_task_potential_weight` | 0.02 | 任务势能辅助损失权重 |
| `aux_barrier_potential_weight` | 0.05 | 障碍势能辅助损失权重 |
| `aux_safety_weight` | 0.1 | 安全辅助损失权重（惩罚接近危险区域）|

### 优化原理

#### 1. 减小安全距离阈值 (`barrier_r_safe: 0.5 → 0.25`)

- **原理**：`r_safe`定义了障碍势能开始快速上升的距离
- **效果**：障碍物的"排斥区域"更小，允许智能体更接近障碍物
- **影响**：势能场中的黑色区域范围显著减小

#### 2. 增大数值稳定性参数 (`barrier_epsilon: 0.005 → 0.02`)

- **原理**：`ε`防止分母为零，同时影响势能函数的陡峭程度
- **效果**：势能曲线更平滑，避免在边界附近出现极端陡峭的梯度
- **影响**：障碍物边界处的势能变化更加平缓，黑色区域边缘更柔和

#### 3. 提高衰减率 (`barrier_decay_rate: 2.0 → 3.0`)

- **原理**：衰减率从2（距离²）提高到3（距离³）
- **效果**：势能随距离增加快速衰减
- **影响**：远离障碍物后势能快速降低到安全水平，减少黑色区域范围

#### 4. 降低强度放大系数

- **`barrier_k_scale: 2.0 → 0.8`**：整体势能强度降低60%
- **`barrier_gradient_scale: 1.5 → 0.8`**：梯度影响降低47%
- **效果**：在保证安全的前提下，减弱势能的整体"推力"

#### 5. 优化危险区域判定

- **`cost_aware_weight: 0.3 → 0.1`**：减少危险区域的额外惩罚
- **`danger_zone_threshold: 0.8 → 0.9`**：只有在激光雷达读数>0.9时才认为处于危险区域
- **效果**：减少不必要的保守行为，允许智能体更灵活地导航

### 数学分析

优化前后势能对比（假设 `k=1`）：

**距离 d = 0.6**（障碍物附近）：
- 优化前：`H = 1 / ((0.6-0.5)² + 0.005) ≈ 95.2`
- 优化后：`H = 0.8 / ((0.6-0.25)³ + 0.02) ≈ 18.0`
- **降低80%**

**距离 d = 1.0**（中等距离）：
- 优化前：`H = 1 / ((1.0-0.5)² + 0.005) ≈ 3.98`
- 优化后：`H = 0.8 / ((1.0-0.25)³ + 0.02) ≈ 1.88`
- **降低53%**

**距离 d = 1.5**（较远距离）：
- 优化前：`H = 1 / ((1.5-0.5)² + 0.005) ≈ 0.995`
- 优化后：`H = 0.8 / ((1.5-0.25)³ + 0.02) ≈ 0.41`
- **降低59%**

可以看出，优化后的势能在各个距离上都显著降低，且衰减更快（距离³ vs 距离²）。

## 预期效果

### 势能场变化

1. **黑色区域显著减小** - 高势能区域范围缩小约50-70%
2. **障碍物间通道打开** - 原本被黑色覆盖的区域变为橙色/黄色，智能体可以通过
3. **势能梯度更平滑** - 颜色过渡更自然，避免突变

### 行为改进

1. **更好的导航能力** - 智能体可以穿过障碍物之间的狭窄通道
2. **减少困住情况** - 不会因为势能过高而无法接近目标
3. **保持安全性** - 在`r_safe=0.25`的距离内仍然有强排斥力
4. **更高效的路径** - 可以选择更直接的路径而不是绕远路

## 安全性保证

虽然降低了势能强度，但安全性仍然得到保证：

1. **硬安全边界**：在`d < r_safe=0.15`时，势能仍然趋向无穷大
2. **四次方衰减**：势能在安全边界附近仍然非常陡峭（距离⁴）
3. **危险区域机制**：当激光雷达读数>0.95时，额外的安全机制会激活
4. **动力学约束**：Port-Hamiltonian系统保证能量守恒，无法"翻越"势能障碍
5. **增强辅助损失**：安全辅助损失惩罚接近危险区域的行为

## 降低Cost的优化

v2.0版本新增以下机制来降低训练和评估cost：

### 新增辅助损失函数

1. **安全损失 (aux_safety_loss)**
   - 惩罚智能体处于危险位置（hazard_proximity > 0.5）
   - 鼓励H_barrier在危险区域有更高响应

2. **梯度对齐损失 (aux_grad_align_loss)**
   - 鼓励障碍势能梯度在接近障碍物时更大
   - 帮助策略学习正确的避障行为

3. **增强的barrier_k损失**
   - 目标k范围从[0.5, 2.5]调整为[0.3, 3.3]
   - 更强的危险区域响应

### 预期效果
- 训练cost从100+降低到50以下
- 评估cost显著降低
- 更好的障碍物避让行为

## 进一步调优建议

如果优化后仍然存在问题，可以考虑：

### 情况1：智能体仍然无法通过狭窄通道
- 进一步减小 `barrier_r_safe` 到 0.1
- 增大 `barrier_epsilon` 到 0.1
- 提高 `barrier_decay_rate` 到 5.0

### 情况2：智能体与障碍物碰撞（cost过高）
- 适当增大 `barrier_r_safe` 到 0.2
- 增大 `barrier_k_scale` 到 0.8
- 增大 `aux_safety_weight` 到 0.2

### 情况3：势能场仍然不够平滑
- 增大 `barrier_epsilon` 到 0.1
- 降低 `barrier_k_scale` 到 0.3
- 调整 `barrier_decay_rate` 在 2.5-4.0 之间
