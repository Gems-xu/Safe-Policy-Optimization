# 障碍势能可视化结果解读

## 问题：为什么障碍势能呈现"太阳"形状？

### 观察现象

在可视化的障碍势能图中，在目标位置 (1.5, 1.5) 和 (-1.5, -1.5) 出现了高能量的"太阳"形状（红色高亮区域），这与预期不符——目标位置应该是**低能量区域**（吸引），而非高能量区域（排斥）。

### 根本原因

这是由于**障碍势能网络混淆了目标激光雷达和障碍激光雷达**导致的：

#### 1. 激光雷达信号相似性

在 Multi-Goal 环境中：
- **障碍激光雷达**（lidar）：检测障碍物，靠近障碍时读数接近 1.0
- **目标激光雷达**（goal_lidar）：检测目标，靠近目标时读数也接近 0.9-1.0

两者信号模式极为相似，都是"高激光雷达读数 = 接近某物体"。

#### 2. 网络学习混淆

障碍势能网络 `H_barrier` 的训练目标是：
```
靠近障碍 → 高激光雷达 → 高势能（排斥）
```

但网络错误地将这个模式泛化为：
```
高激光雷达 → 高势能
```

因此，当智能体靠近目标时：
```
靠近目标 → 高目标激光雷达 → 【错误】高势能
```

#### 3. 可视化代码加强了这一现象

在可视化代码 `_create_dummy_observation()` 中，我们模拟目标激光雷达：

```python
# 在目标位置附近，目标激光雷达读数很高
goal_dist_red = np.sqrt((x - 1.5)**2 + (y - 1.5)**2)
if goal_dist_red < 1.0:
    obs[goal_lidar_start:goal_lidar_end] = 0.9  # 高读数
```

这导致可视化时，目标位置被网络识别为"高激光雷达区域"，从而产生高障碍势能。

---

## 解决方案

### 短期解决（可视化修复）

修改可视化代码，降低目标激光雷达读数：

```python
# 在 _create_dummy_observation() 中
if goal_dist_red < 1.0:
    obs[goal_lidar_start:goal_lidar_end] = 0.3  # 降低到 0.3
```

这样可以在可视化中避免"太阳"现象，但**不解决训练问题**。

### 长期解决（训练改进）

#### 方案1: 特征工程

在观测预处理中添加特征，帮助网络区分：

```python
# 在 obs 中添加新的特征维度
obs[new_dim] = obstacle_lidar_max - goal_lidar_max  # 差分特征
```

#### 方案2: 分离网络输入

为障碍势能网络只提供障碍相关特征（去除目标激光雷达）：

```python
# 在 barrier_phs_pinn_actor.py 中
barrier_obs = obs.clone()
barrier_obs[:, goal_lidar_start:goal_lidar_end] = 0.0  # 屏蔽目标信号
H_barrier = self.barrier_potential_net(barrier_obs)
```

#### 方案3: 对抗训练

在训练中添加正则项，惩罚目标位置的高障碍势能：

```python
# 在 loss 中添加
goal_penalty = H_barrier[at_goal_positions].mean()
loss += lambda_goal * goal_penalty
```

#### 方案4: 调整激光雷达编码

修改环境或包装器，使目标激光雷达使用不同的值域：

```python
# 障碍: [0, 1]，目标: [-1, 0]
goal_lidar = -goal_lidar  # 反转信号
```

## 理论参考

### 期望的障碍势能特性

根据 [Barrier_PHS.md](../Barrier_PHS.md)，障碍势能应满足：

```
H_barrier(x) = k / ((d(x) - r_safe)² + ε)

性质：
1. d(x) → r_safe 时，H_barrier → ∞ (硬安全保证)
2. d(x) >> r_safe 时，H_barrier → 0 (远离障碍时无影响)
3. ∇H_barrier 应指向远离障碍的方向
```

### 当前问题

目标位置不是障碍，因此 `d(goal) >> r_safe`，理应 `H_barrier(goal) ≈ 0`。

但由于激光雷达混淆，网络错误地认为 `d(goal) ≈ r_safe`，导致 `H_barrier(goal) >> 0`。
